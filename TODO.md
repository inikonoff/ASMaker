# План развития ASMaker

## В работе / следующие

Порядок согласован 8 ноября 2026. Свободный поворот идёт раньше производственного пакета: метки и чертёж должны сразу понимать повёрнутые карманы.

### Этап 1 — быстрые улучшения
- [x] **Вёрстка PDF спецификации:** таблица не рвётся без нужды — если целиком помещается на новый лист, переносится целиком; длинная таблица делится с повтором шапки, заголовок раздела не остаётся внизу листа один.
- [x] **Размеры и расстояния** (чекбокс «Показывать размеры и расстояния»): при перетаскивании и у выделенного — расстояния до соседей и краёв подложки.
- [x] **QR-код** как элемент: ссылка или текст, размер, цвет, фон.
- [x] **Подходящие цвета:** под полем цвета — дополнительный, аналоговые, триада от выбранного; плюс «цвета проекта». Опционально.
- [x] **Тень у текста:** цвет, размытие, смещение.
- [x] **Отделка отверстий** (в их свёртке): без отделки, кругляш-заглушка в цвет самоклейки (на виде для клиента не видно), декоративная шляпка Ø10 мм — белая, серебро, золото (лёгкий объём градиентом). Шляпки и заглушки — в смете.
- [x] **Свойства по «свёрткам»:** логично сгруппировать похожие свойства, все группы сворачиваются, состояние запоминается.

### Этап 2 — свободный поворот
- [x] Любой угол у карманов, слоёв и текста: ручка поворота на холсте (Shift — шаг 15°), поле «Угол» в свойствах. Привязка, пересечения, предупреждения и экспорт — по повёрнутому контуру. Проклейка и смета не меняются (считаются в осях кармана). Пример: конверты 10×15 «висят» на ветках дерева.

### Этап 3 — группы
- [ ] Группировка слоёв (Ctrl+G / Ctrl+Shift+G): группа двигается, поворачивается, скрывается и блокируется целиком, сворачивается в панели слоёв. Вставка стиля в группу применяется ко всем подходящим элементам внутри.

### Этап 4 — раскладка и шаблоны
- [ ] **Мастер раскладки:** «N карманов формата X, зазор, поля, место под заголовок, выравнивание» → готовая раскладка; продолжение «Расставить сеткой».
- [ ] **Шаблоны стендов** на основе мастера (информационный, меню/прайс, расписание, 6/9/12 карманов) и **«Сохранить как шаблон»** для любого своего проекта.

### Этап 5 — вид для клиента
- [ ] Переключатель «Производство / Клиент»: в клиентском виде скрыты линии раздела, названия карманов, подписи размеров и технические метки — для показа и картинки на согласование. Отверстия — по их отделке (см. этап 1).

### Этап 6 — пакет для цеха
- [ ] **Основа с метками сборки** (чекбокс «Печатать метки на основе»): центры отверстий (крестик и окружность), Г-метки по внешним углам карманов (у скошенного уголка — по срезу, у повёрнутых — по повёрнутому контуру). По частям, с белым полем.
- [ ] **Чертёж для цеха:** PDF в масштабе с размерными линиями, координатами карманов и отверстий, спецификация на отдельном листе.
- [ ] **Экспорт по полосам** (300 dpi и выше): TIFF полосами, PNG и PDF потоковым сжатием, индикатор прогресса. Лимит ~150 Мп снимается для всех форматов, кроме JPEG.
- [ ] Всё вместе — одной кнопкой «Пакет для цеха» (ZIP).
