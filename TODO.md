# План развития ASMaker

## В работе / следующие

- [ ] **Экспорт основы с разметкой.** Картинка подложки (фон, заливка, слои под карманами) в полном разрешении и с теми же настройками экспорта: формат, dpi, цветовой профиль, вылеты, метки реза. Поверх неё — метки для сборки:
  - центры отверстий под крепёж: крестик и окружность нужного диаметра;
  - уголки всех карманов: Г-образные метки по внешним углам, по которым карман клеится на место; у скошенного уголка метка повторяет срез.

  Карманы, скотч и текст поверх карманов в этот экспорт не входят. Нужен, чтобы напечатать основу и по меткам точно наклеить карманы и просверлить отверстия.
- [ ] **Экспорт больших размеров (300 dpi и выше) по полосам.** Сейчас стенд рисуется в браузере одной огромной картинкой, поэтому большие разрешения упираются в память и лимит ~150 Мп. Нужно рендерить и записывать файл по горизонтальным полосам:
  - TIFF — полосами (strips), как и задумано форматом;
  - PNG и PDF — потоковым сжатием по мере готовности полос;
  - полоса индикатора прогресса, интерфейс не замирает.

  Ограничением останется только размер итогового файла. JPEG браузер кодирует только целиком, для него лимит сохранится.
- [ ] **Своё контекстное меню** на правую кнопку мыши: копировать, вставить, дублировать, удалить, порядок слоя, повернуть, отразить, заблокировать. Холст тогда двигается пробелом или средней кнопкой.
- [ ] **Чертёж для цеха:** PDF в масштабе с размерными линиями, координатами карманов и отверстий, спецификацией на отдельном листе.
